# Archived experiment notebooks

`03_model_experiments.ipynb` is the completed, self-contained baseline notebook retained with its historical outputs and original narration. It is audit and learning evidence, not the current executable experiment entry point.

Current experiments execute through the installed `ids-run-*` commands. [The screening analysis notebook](../../notebooks/03_model_screening_analysis.ipynb) presents screening evidence, and [the results report](../../RESULTS.md) records tuning and final evaluation.
